# African Logistics Cost Map

This interactive visualization displays average logistics costs between African countries (as origins) and global destinations based on the dataset generated by `create_africa_avg_cost.py`.

## Opening the Map

1. Ensure the web server is running with:
   ```
   cd chiff
   python3 -m http.server 8000
   ```

2. Open your web browser and navigate to:
   ```
   http://localhost:8000/africa_logistics_cost_map.html
   ```

## Features of the Map

### Interactive Map Elements

- **Routes**: Colored lines connecting African origin countries to global destinations
  - Green: Low cost
  - Yellow: Medium cost
  - Red: High cost
  - Hover over a route to see detailed cost information

- **Country Markers**: 
  - Red circles: African origin countries
  - Blue circles: Destination countries
  - Hover over any country to see its name and ISO code

### Filtering Options

The map provides several filtering options to help you analyze specific logistics routes:

1. **Origin Country Filter**: Select a specific African country as the origin
2. **Commodity Filter**: Filter by commodity type
3. **Destination Country Filter**: Focus on specific destination countries
4. **Reset View**: Reset all filters and map zoom

### Cost Legend

The cost legend shows the gradient from:
- Green (Low cost)
- Yellow (Medium cost)
- Red (High cost)

## Data Analysis Tips

1. **Filtering by Origin**: Select a specific African country to see all its export routes
2. **Commodity Analysis**: Choose a commodity to see which routes are most cost-effective for that product
3. **Regional Analysis**: Use the zoom feature to focus on specific regions

## Troubleshooting

If the map doesn't load properly:
1. Check that the data file exists at the specified path
2. Ensure the web server is running
3. Try clearing your browser cache

## About the Data

This visualization uses data aggregated from the original dataset (`imputed_full_matrix_at_centroid.csv`), which has been processed to calculate average logistics costs between countries by commodity type.

The aggregation script (`create_africa_avg_cost.py`) performs the following operations:
1. Filters for African countries as origins
2. Groups data by origin country, destination country, and commodity type
3. Calculates the average unit logistics cost for each group
4. Saves the results to a new dataset (`africa_avg_cost_by_commodity.csv`)
